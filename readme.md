# CourseMoth

Open-source video player for downloaded courses.  
Local offline library, progress tracking, daily tasks and streaks.
Offline-first, no telemetry, no online servers, everything is yours!

## Platforms
- Windows 10 and above
- Android 10 and above
- *iOS and MacOS in the feature*

## Core Features (TBD)
- Video player
- Progress for lessons, modules, and courses
- Daily tasks and streaks
- Import courses from local folders or from PC
- Auto-detect structure: course / module / lesson
- Course library with categories and statuses

## Stack
- .NET MAUI
- SQLite
- MVVM

## Status
Early stage. MVP: local library, player, progress.
